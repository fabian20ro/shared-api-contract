# Contributing

This repository is a generated public distribution of canonical contract files maintained by shared-api-host.

For proposals:

1. Open an issue describing the compatibility problem or requested capability.
2. Include the affected module manifest/handler behavior.
3. State whether existing contractVersion 1 modules can remain unchanged.
4. Do not include credentials, provider IDs or private deployment information.

Accepted changes are implemented in the private canonical source, validated against both public applications, and published here as a new tagged release.
